# Таймер презентации v5

Автономный 64-разрядный таймер для Windows 10/11, который отображается поверх
PowerPoint, PDF-презентаций и браузера. Установка и .NET не требуются.

## Быстрый старт

1. Запустите `PresentationTimer-v5.exe`.
2. Нажмите правой кнопкой по таймеру и откройте **Настройки**.
3. Выберите продолжительность, размер, цвета, прозрачность, звук и тему.
4. Перетащите таймер в удобное место.
5. Нажмите `Ctrl+Alt+Пробел`, чтобы запустить отсчёт.
6. Нажмите `Ctrl+Alt+F1`, чтобы открыть наглядную справку.

## Темы

- **Умное стекло** — основная тема: компактная карточка и шкала времени.
- **Эфирный минимализм** — цифры без фоновой карточки.
- **Кольцо прогресса** — круговой индикатор оставшегося времени.

Смена темы, цвета, прозрачности или размера не сбрасывает работающий отсчёт.
Изменение исходной продолжительности сбрасывает таймер на новое значение.

## Горячие клавиши

| Сочетание | Действие |
|---|---|
| `Ctrl+Alt+Пробел` | Старт или пауза |
| `Ctrl+Alt+R` | Сброс к исходному времени |
| `Ctrl+Alt+S` | Настройки |
| `Ctrl+Alt+↑` | Добавить минуту |
| `Ctrl+Alt+↓` | Убрать минуту |
| `Ctrl+Alt+H` | Скрыть или показать таймер |
| `Ctrl+Alt+F1` | Наглядная справка |

При конфликте с другой программой таймер сообщает, какое сочетание не удалось
зарегистрировать. Все действия также доступны через значок приложения рядом с часами.

## Управление мышью

- двойной щелчок — старт или пауза;
- перетаскивание — изменение положения;
- правый щелчок — настройки.

Если включён пропуск кликов, используйте горячие клавиши или значок рядом с часами.

## Завершение отсчёта

В последнюю минуту цифры меняют цвет. После завершения остаётся `00:00`, которое
мигает белым и предупреждающим цветом. Один раз воспроизводится выбранный встроенный
сигнал. Кнопка **Прослушать** позволяет проверить его в настройках.

## Повторная сборка

Проект состоит из модулей `main`, `timer`, `renderer`, `settings` и `platform`.
Для сборки на Windows запустите `build-windows.bat`. Команда для Linux/macOS
находится в `build-windows.sh`.

## Проверка на Windows

После скачивания рекомендуется один раз проверить:

1. запуск поверх полноэкранной презентации PowerPoint;
2. переключение всех трёх тем без сброса работающего отсчёта;
3. перемещение между мониторами с разным масштабом Windows;
4. скрытие таймера, открытие настроек из трея и закрытие настроек без появления таймера;
5. три сигнала кнопкой **Прослушать**;
6. справку по `Ctrl+Alt+F1` и остальные глобальные сочетания.

Приложение пока не подписано цифровой подписью, поэтому Windows SmartScreen может
показать предупреждение при первом запуске.
