# Таймер презентации v5.1.1

Автономный 64-разрядный таймер для Windows 10/11, который отображается поверх
PowerPoint, PDF-презентаций и браузера. Установка и .NET не требуются.

## Быстрый старт

1. Скачайте [ZIP для Windows x64](PresentationTimer-v5.1.1-Windows-x64.zip), распакуйте его и запустите `PresentationTimer-v5.1.1.exe`.
2. Нажмите правой кнопкой по таймеру и откройте **Настройки**.
3. Выберите продолжительность, размер, цвета, прозрачность, звук и тему.
4. Перетащите таймер в удобное место.
5. Нажмите `Ctrl+Alt+Пробел`, чтобы запустить отсчёт.
6. Нажмите `Ctrl+Alt+F1`, чтобы открыть наглядную справку.

## Автоматический контраст цифр

В **Настройках** отметьте **Автоконтраст цифр по фону под таймером** и нажмите
**Сохранить**. Для прозрачного таймера поверх слайдов выберите тему
**Эфирный минимализм**. В остальных темах учитывается и цвет собственной
подложки таймера, и её прозрачность: на непрозрачной подложке цвет цифр
может не меняться при смене слайда.

На светлой области под цифрами таймер выбирает чёрный цвет, на тёмной —
белый. Тонкая контрастная обводка помогает на пёстром фоне. Проверка
включена, пока таймер виден, даже на паузе. Режим не изменяет сохранённые
вручную цвета и не сбрасывает отсчёт. Снимите отметку, чтобы вернуть
ручное оформление. Старые настройки без этого параметра открываются в
ручном режиме.

Автоконтраст работает локально, анализирует небольшую выборку области
экрана под цифрами и не сохраняет и не передаёт изображения. Если
обновить выборку не удаётся, сохраняется предыдущий цвет, а до первой
удачной выборки используются ручные цвета. При защищённом видео, на
удалённом рабочем столе или при особенностях видеодрайвера экран может
возвращать неверную выборку; для таких случаев переключитесь на ручной цвет.

## Темы

- **Умное стекло** — основная тема: компактная карточка и шкала времени.
- **Эфирный минимализм** — цифры без фоновой карточки.
- **Кольцо прогресса** — круговой индикатор оставшегося времени.

Смена темы, цвета, прозрачности или размера не сбрасывает работающий отсчёт.
Изменение исходной продолжительности сбрасывает таймер на новое значение.

## Горячие клавиши

| Сочетание | Действие |
|---|---|
| `Ctrl+Alt+Пробел` | Старт или пауза |
| `Ctrl+Alt+0` | Сброс к исходному времени (0 в верхнем ряду) |
| `Ctrl+Alt+S` | Настройки |
| `Ctrl+Alt+↑` | Добавить минуту |
| `Ctrl+Alt+↓` | Убрать минуту |
| `Ctrl+Alt+H` | Скрыть или показать таймер |
| `Ctrl+Alt+F1` | Наглядная справка |

При конфликте с другой программой таймер сообщает, какое сочетание не удалось
зарегистрировать. Все действия также доступны через значок приложения рядом с часами.

## Управление мышью

- двойной щелчок — старт или пауза;
- перетаскивание — изменение положения;
- правый щелчок — настройки.

Если включён пропуск кликов, используйте горячие клавиши или значок рядом с часами.

## Завершение отсчёта

В ручном режиме в последнюю минуту цифры меняют цвет, а после завершения
`00:00` мигает белым и предупреждающим цветом. В авторежиме цифры
сохраняют контраст: предупреждающий цвет показывает индикатор прогресса,
а при завершении индикатор мигает. Выбранный звуковой сигнал
воспроизводится один раз. Кнопка **Прослушать** позволяет проверить его в настройках.

## Повторная сборка

Проект состоит из модулей `main`, `timer`, `renderer`, `settings` и `platform`.
Для сборки на Windows установите Zig 0.15.2 и запустите `build-windows.bat`. Команда для Linux/macOS
находится в `build-windows.sh`.

## Проверка на Windows

После скачивания рекомендуется один раз проверить:

1. запуск поверх полноэкранной презентации PowerPoint;
2. переключение всех трёх тем без сброса работающего отсчёта;
3. перемещение между мониторами с разным масштабом Windows;
4. скрытие таймера, открытие настроек из трея и закрытие настроек без появления таймера;
5. три сигнала кнопкой **Прослушать**;
6. справку по `Ctrl+Alt+F1` и остальные глобальные сочетания;
7. автоконтраст при смене белого слайда на чёрный и обратно в режиме
   показа, как на паузе, так и при запущенном отсчёте;
8. стекло/кольцо с разным уровнем прозрачности, пёстрый фон и перенос
   между экранами; отключение авторежима и возврат ручного цвета.

Сборка EXE для Windows x64 проверена кросс-компиляцией. Модульные
тесты расчёта яркости, прозрачности и переключения цвета:

```sh
cc -std=c11 -Wall -Wextra -Werror tests/contrast-test.c -lm -o contrast-test
./contrast-test
```

Запуск графической программы на Windows и поверх PowerPoint в ходе
подготовки этой сборки не проверялся.

Приложение пока не подписано цифровой подписью, поэтому Windows SmartScreen может
показать предупреждение при первом запуске.
