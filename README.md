# Таймер презентации — готовое приложение для Windows

`PresentationTimer.exe` — автономный таймер обратного отсчёта поверх PowerPoint,
PDF-презентаций, браузера и других окон Windows. Установка и .NET не требуются.

## Первый запуск

1. Запустите `PresentationTimer.exe`.
2. Щёлкните таймер правой кнопкой мыши и выберите настройки.
3. Задайте время, размер и цвета цифр.
4. Перетащите таймер в нужное место экрана.
5. При необходимости включите пропуск кликов мыши — презентацией можно будет
   управлять прямо «сквозь» таймер.

Приложение также доступно через значок рядом с часами Windows.

## Управление во время презентации

- `Ctrl+Alt+Space` — старт / пауза;
- `Ctrl+Alt+R` — сброс к заданному времени;
- `Ctrl+Alt+S` — настройки;
- `Ctrl+Alt+↑` — добавить минуту к оставшемуся времени;
- `Ctrl+Alt+↓` — убрать минуту;
- двойной щелчок по таймеру — старт / пауза;
- правый щелчок — настройки;
- перетаскивание мышью — изменить положение.

Если включён пропуск кликов, используйте горячие клавиши или значок рядом с
часами. Настройки сохраняются автоматически в профиле Windows.

## Совместимость

Windows 10/11, 64-разрядная версия. Приложение не подписано цифровой подписью,
поэтому при первом запуске Windows SmartScreen может показать предупреждение.

## Повторная сборка

Исходный файл: `PresentationTimer.c`. Пример сборки с Zig 0.14:

```bat
zig cc PresentationTimer.c -target x86_64-windows-gnu -municode ^
  -O2 -s -Wl,--subsystem,windows -o PresentationTimer.exe ^
  -luser32 -lgdi32 -lshell32 -lcomdlg32
```
